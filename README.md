# North Bali Kids Library — website bilingual

## Cara publikasi gratis dengan GitHub Pages

1. Daftar/login di https://github.com.
2. Klik **New repository**. Untuk alamat `https://USERNAME.github.io`, beri nama repository **USERNAME.github.io** (USERNAME harus sama persis dengan username GitHub). Pilih **Public**.
3. Klik **Add file → Upload files**. Upload `index.html` dari folder ini (harus berada di root repository), lalu klik **Commit changes**.
4. Buka **Settings → Pages**. Di **Build and deployment**, pilih **Deploy from a branch**, branch **main**, folder **/(root)**, lalu **Save**.
5. Tunggu beberapa menit dan buka `https://USERNAME.github.io`.
6. Bagikan URL ke WhatsApp dan Instagram. Untuk pencarian Google, verifikasi situs di https://search.google.com/search-console/ dan minta pengindeksan. Google tidak menjamin peringkat atau waktu indeks.

## Mengedit isi

- Semua isi dan terjemahan berada di file `index.html`, dalam objek `translations` pada bagian bawah file.
- Untuk memperbarui file, buka repository GitHub, klik `index.html`, ikon pensil **Edit**, lalu **Commit changes**.
- Tombol EN/ID mengubah bahasa tanpa reload dan menyimpan pilihan bahasa pada browser.
- Foto dalam bagian Gallery saat ini adalah placeholder. Ganti setelah memperoleh foto resmi dan izin penggunaan foto anak.
- Sebelum publikasi final, pastikan alamat lengkap, jam buka, kontak, dan rincian membership sudah benar. Saat ini sengaja belum dicantumkan.
- Instagram resmi: https://www.instagram.com/northbalikidslibrary/

## Catatan

Hosting GitHub Pages gratis untuk repository publik pada paket Free, dengan batas pemakaian wajar. Domain `github.io` gratis; domain pribadi berbayar bila dipilih. Website ini statis tanpa backend dan tidak mengumpulkan data pribadi pengunjung.
